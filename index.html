Kuroneko Web production
Web制作への思い

Kuroneko Web Productionは、埼玉県を拠点に、お客様一人一人に寄り添ったWeb制作を提供しております。
多くのディレクター、デザイナー、コーダーが所属するコミュニティと連携し、フリーランスならではの【柔軟な対応】【コストパフォーマンス】を最大限に活かして、丁寧かつ迅速なサービスを心がけています。
屋号を決めるにあたり、どうしても愛猫である【黒猫】の要素を取り入れたいという思いから、【Kuroneko Web Production】という名前にいたしました。
猫の手も借りたいほど忙しくなることを願い、また、一人ではなく支えてくれる仲間やパートナーの存在を忘れないようにという思いが込められております。
飲食店のウェイターをしていた頃、自分の店を客観的に見つめ、常に改善点を探していました。
イベントの企画やメニューの提案、ティーカップの買い付けから備品の選定まで、あらゆる面で工夫を重ねる毎日。
現在は形を変え、ホームページ制作を通じてお客様や企業をマルチにサポートしていきたいと考えております。
